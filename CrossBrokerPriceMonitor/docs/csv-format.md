# CSV Log Format

This document describes the CSV files generated by the MT5 agents and the Windows coordinator.

## 1. Agent tick log

Example filename:

```text
CrossBrokerTicks_A_BTCUSD_20260803.csv
```

Recommended columns:

```text
utc_time,local_time,agent_id,broker_label,symbol,bid,ask,spread,volume,last,flags
```

### Fields

- `utc_time`: Quote timestamp in UTC using ISO 8601.
- `local_time`: Local terminal time.
- `agent_id`: Logical agent identifier such as `A` or `B`.
- `broker_label`: Human-readable broker name.
- `symbol`: Broker-specific symbol name.
- `bid`: Current Bid price.
- `ask`: Current Ask price.
- `spread`: `ask - bid` in price units.
- `volume`: Tick volume when available.
- `last`: Last traded price when available.
- `flags`: Raw MQL5 tick flags.

Example:

```csv
utc_time,local_time,agent_id,broker_label,symbol,bid,ask,spread,volume,last,flags
2026-08-03T08:10:15.421Z,2026-08-03 11:40:15.421,A,Broker A,BTCUSD,64250.10,64252.30,2.20,1,64251.20,6
```

## 2. Coordinator raw quote log

Example filename:

```text
raw_quotes_20260803.csv
```

Columns:

```text
received_utc,agent_id,broker_label,symbol,source_time_utc,bid,ask,mid,spread,age_ms,connection_state
```

### Fields

- `received_utc`: Time when the coordinator received the message.
- `source_time_utc`: Timestamp generated by the MT5 agent.
- `mid`: `(bid + ask) / 2`.
- `age_ms`: Quote age measured by the coordinator.
- `connection_state`: State such as `CONNECTED`, `STALE`, or `DISCONNECTED`.

## 3. Coordinator comparison log

Example filename:

```text
comparisons_20260803.csv
```

Columns:

```text
utc_time,agent_a_symbol,agent_b_symbol,a_bid,a_ask,b_bid,b_ask,buy_a_sell_b,buy_b_sell_a,mid_gap,a_age_ms,b_age_ms,status
```

### Calculations

```text
buy_a_sell_b = b_bid - a_ask
buy_b_sell_a = a_bid - b_ask
mid_gap       = ((b_bid + b_ask) / 2) - ((a_bid + a_ask) / 2)
```

Example:

```csv
utc_time,agent_a_symbol,agent_b_symbol,a_bid,a_ask,b_bid,b_ask,buy_a_sell_b,buy_b_sell_a,mid_gap,a_age_ms,b_age_ms,status
2026-08-03T08:10:15.500Z,BTCUSD,BTCUSDm,64250.10,64252.30,64265.40,64268.00,13.10,-17.90,15.50,79,61,ALERT
```

## Status values

Suggested comparison status values:

- `NORMAL`: Both executable edges are below warning level.
- `WARNING`: At least one edge exceeds `WarningUsd`.
- `ALERT`: At least one edge exceeds `AlertUsd`.
- `STALE_A`: Agent A quote is stale.
- `STALE_B`: Agent B quote is stale.
- `STALE_BOTH`: Both quotes are stale.
- `WAITING`: One or both agents have not sent a valid quote yet.

## Data analysis notes

- Do not compare rows using only wall-clock timestamps; use the quote ages too.
- Different brokers may use different symbol names, contract sizes, price precision, or mark-up models.
- A positive executable edge is not net profit.
- Commission, slippage, funding, latency, and failed fills must be modeled separately.
- For research, preserve raw quote logs and derive comparison data in a separate process whenever possible.

## Excel and Python compatibility

Files are UTF-8 CSV with a comma delimiter. When importing into Excel, explicitly select UTF-8 if non-English broker labels are used.

Python example:

```python
import pandas as pd

quotes = pd.read_csv("raw_quotes_20260803.csv", parse_dates=["received_utc", "source_time_utc"])
comparisons = pd.read_csv("comparisons_20260803.csv", parse_dates=["utc_time"])
```
